# 菌养食材网站 · UI 方向提案

依据：栏目设置.docx、菌养食材基础信息.docx、菌养食材网站栏目与内容整合.docx。

本轮用途：选择视觉方向。效果图是设计预览，按钮尚不能点击；选择后再制作可点击的前端页面。

## 三种方向

| 方案 | 配色与图像 | 布局性格 |
| --- | --- | --- |
| A 自然田园 | 米白、森林绿、淡橄榄；蔬菜与田园照片 | 留白较多，左右分栏首屏，清晰的食材分类与基地入口 |
| B 清爽科技 | 白、深青绿、浅薄荷；种植基地照片 | 界面整齐，强调生产记录与检测资料的查询入口 |
| C 温暖食材 | 暖奶油、陶土色、橄榄绿；蔬菜、鸡蛋、木质餐桌 | 亲切的食材摄影与编辑式排版，适合产品展示 |

推荐优先比较 A：食材与农业主题直观，也适合延展基地溯源和科普页面。

## 内容与交互范围

- 保留文档中六项主导航，不增加购物车、支付、账户或后台功能。
- 初版重点是页面布局和跳转，筛选、标签切换、返回列表等使用前端交互。
- 每种页面仅放少量有说明的演示条目，避免大量填充文字。
- 价格、基地名称、批次、检测结果等未提供的信息使用“待补充”或明确的演示状态。
- 无报告时显示“资料待补充”，不预设“合格”状态；报告按钮仅在有文件时开放。
- 效果图中的生成照片用于选择风格，不代表真实产品或基地。
- 网站中的“菌养”指微生物技术相关的种植和养殖，视觉使用食材与基地，不将其误做为蘑菇专卖网站。
- 后续支持手机端：主导航折叠，首屏上下布局，分类与筛选保持可操作。

## 本轮图像生成简报

使用内置 ImageGen，分别生成 A/B/C 三张独立首页 UI 效果图；不使用拼贴或设备外框。三张图共用导航、标题和按钮，以便直接比较视觉风格。

共用导航：菌养食材；首页、菌养食材、肥料与饲料、基地溯源、科普知识、食材安全事件。

共用标题：了解菌养食材 / 看见生产与检测过程。

共用短说明：连接食材、基地与生产记录。

共用主按钮：浏览菌养食材、查看基地溯源。

共用食材分类：蔬菜类、瓜果类、家禽肉类、蛋奶类。

构图：清楚的桌面首页，简短首屏加轻量内容延续；所有界面文本和控件在后续前端中由原生 HTML/CSS 实现，照片为独立素材。强调中文可读性、留白、自然食材摄影，不加入虚构价格、检测结论、认证或效果数字。
