# 菌养食材 UI 交付与审查记录

## 内容依据

以《菌养食材网站栏目与内容整合.docx》为主，结合《栏目设置.docx》和《菌养食材基础信息.docx》。网站定位为微生物参与种植、养殖及生产过程的食材展示，包含菌养食材、肥料与饲料、基地溯源、科普知识、食材安全事件，并非食用菌专卖或禽肉专卖。

示例食材、投入品及基地用于呈现页面结构，均保留演示与待补充状态。没有虚构售价、检测通过结论、证书或下载报告。

## A2 设计对照

| 对照点 | 实现与核对结果 |
| --- | --- |
| 色彩 | 米白背景 #F6F4EA、森林绿 #234D37、浅绿色选中背景，已对照 A2 三张参考图 |
| 左侧导航 | 桌面展开 240px、收起 76px；滑动选中标记随滚动更新，原生按钮支持键盘 |
| 首屏 | 大标题、食材摄影、探索入口与介绍内容；轻量进入动画，无整页截图覆盖交互 |
| 页面延续 | 食材、肥料与饲料、基地、科普、事件按长页依次展开，点击进入列表与详情 |
| 图片 | 独立生成农业、果品、禽类、蛋类、肥料、饲料和基地摄影；食材卡片保持 4:3 |
| 空间与字体 | 保留 A2 的自然简洁方向；系统中文字体和较宽松的长页间距是有意调整 |
| 移动端 | 960px 以下为抽屉导航，390px 手机和 1024px 窄桌面均无横向溢出 |

摄影素材与生成式概念图不完全相同；科普区提供三个可点击内容入口。页面使用真实 HTML、CSS 与 JavaScript，可编辑、筛选与导航。
