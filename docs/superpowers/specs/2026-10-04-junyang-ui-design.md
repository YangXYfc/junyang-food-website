# 菌养食材网站 · A 方案修订设计

状态：用户已确认“菌养食材，按照文档来”，并授权构建站点及完成后审查；进入实施。

## 目标与依据

根据三个 Word 文档建立轻量、美观的食材展示网站。用户已选择接近 A 的自然田园风格，并要求左侧统一导航、可收起展开的侧栏、随滚动突出当前栏目、入场动画和能够持续向下探索的首页。

内容依据：`栏目设置.docx`、`菌养食材基础信息.docx`、`菌养食材网站栏目与内容整合.docx`。以第三份整合文档为主要页面结构。

视觉参考：[OpenAI GPT-6.1 Sol 页面](https://openai.com/zh-Hans-CN/index/introducing-gpt-6-1-sol/)。参考其分节长页和内容目录的组织方式。网页文本已读取，浏览器动态画面连续加载超时，未确认其实际入场动画；下面的动画是依据用户描述设计的行为。

## 视觉系统

- 背景：米白 `#F6F4EA`；正文阅读区可采用更淡的同色背景。
- 主色：森林绿 `#234D37`；选中项采用浅鼠尾草色 `#E3EADB`。
- 正文：深灰绿 `#35463A`；次要说明 `#71796B`；边界 `#DCE0D3`。
- 大标题采用中文衬线字体；导航、正文和按钮采用中文无衬线字体；字号均由前端统一定义。
- 桌面正文 16–18px，导航 16px，按钮 16px；首屏大标题 48–64px，分两至三行，不能伸入照片或侧栏。
- 主按钮森林绿底、米白字；次按钮透明底、绿色边框；控件圆角 6–10px，少量细分隔线。
- 图像以蔬菜、瓜果、禽肉、蛋奶、土壤和种养基地为主题。“菌养”不被表现为蘑菇专卖。
- 内容区采用开放式布局、摄影横幅、列表和有用途的产品卡片；避免每节都套大卡片。
- 生成照片仅供 UI 演示，不代表实际产品、真实基地或检测证据。

## 左侧导航

### 桌面展开状态

固定在左侧，宽度 240px，高度占满视口。顶部展示“菌养食材”，中部依次排列：

1. 首页
2. 菌养食材
3. 肥料与饲料
4. 基地溯源
5. 科普知识
6. 食材安全事件

每项使用一致的线性图标、文字和间距。底部提供“收起侧栏”按钮。正文从侧栏右侧开始，不能被覆盖。顶部不再重复这组六个导航。

“顶部按钮移到左侧”理解为六项主导航。正文内的“浏览菌养食材”“查看基地”等行动按钮仍保留在关联内容处，使页面阅读与跳转相连。

### 当前栏目与滑动反馈

当前项采用浅鼠尾草色背景、深绿文字和左侧绿线。高亮背景在栏目间垂直移动，持续 240ms，采用缓入缓出；悬停轻微改变背景，键盘焦点有清楚边框。

首页根据滚动位置更新当前项：以视口高度约 35% 的位置作为阅读线。介绍区属于“首页”；食材区、肥料饲料区、基地区、知识区、事件区依次对应同名导航。到达页尾时保持“食材安全事件”选中，不能回跳。

点击首页左栏栏目，平滑滚动到对应内容区，并更新 URL 中的锚点。滚动期间不抢占焦点；点击目标完成后保留清楚的键盘访问路径。浏览器前进后退能够返回对应位置。

独立列表或详情页面使用同一侧栏。进入食材详情时高亮“菌养食材”，进入基地详情时高亮“基地溯源”；这里高亮所属栏目，不能因滚动到详情内部的小标题而跳到其他栏目。

### 收起状态

收起为 76px 的图标栏，仍保留六个栏目和底部展开按钮。悬停与键盘聚焦时显示栏目名称；按钮含可访问名称。选中背景与绿线保留。

展开/收起使用 280ms 的宽度和正文位置过渡，内容文字不压缩变形。状态仅在本地保存；手机访问不继承桌面窄栏状态。

### 手机与窄屏

宽度低于 960px 时改为左侧抽屉，由固定的菜单按钮展开。抽屉关闭时正文占满屏幕；展开时背景轻遮罩，点击遮罩或 Escape 关闭，焦点限制在抽屉内并在关闭时返回菜单按钮。选择栏目后自动关闭。所有主要触控目标至少 44px。

## 可向下探索的首页

### 1. 首页首屏与介绍

首屏保留 A 的食材篮摄影与自然留白。标题为“了解菌养食材 / 看见生产与检测过程”，短说明为“连接食材、基地与生产记录”，按钮为“浏览菌养食材”“查看基地溯源”。桌面图文分栏，手机上下排列。

首屏底部提供“向下探索”按钮，点击滚动到介绍区。下一节可以在首屏底部露出少量内容，提示页面还可继续浏览。

介绍区标题“从微生物，到日常食材”，用少量文字介绍网站覆盖种植、养殖、食材、生产记录与检测资料。用简短流程“微生物技术 → 种植与养殖 → 食材 → 检测与溯源”连接后续内容，不加入未经核实的技术效果数字。

### 2. 菌养食材

展示蔬菜类、瓜果类、家禽肉类、蛋奶类四类食材照片与入口，并有“查看全部食材”。分类入口进入食材列表并选择对应分类。

列表包含分类和来源基地筛选，卡片显示图片、名称、规格、价格和资料状态。演示条目清楚标明；缺少实际资料的字段显示“待补充”。详情页展示图片、基本信息、来源基地、批次与检测资料入口。

### 3. 肥料与饲料

首页采用两个开放式图文展示：微生物肥料、发酵饲料。各放一小段介绍与“了解肥料”“了解饲料”。进入栏目后用肥料/饲料标签切换，详情展示分类、成分、适用对象、使用方法和标准资料字段。

### 4. 基地溯源

使用农田或温室大幅摄影与简短说明“看见食材的生产过程”。明确入口为“查看基地”和“查看生产过程”。生产过程入口先进入基地列表并提示选择基地，不能直接打开无归属的虚构批次。

基地详情采用介绍、生产过程、日常管理、指标监测、关联食材的结构。时间线与指标表只展示清楚标明的演示内容；没有实际记录时使用空状态。区分环境监测与食材检测。

### 5. 科普知识

用两至三个短文章入口展示“认识微生物”“了解菌养机理”等主题。提供查看全部文章。栏目采用主题列表与文章详情；正式科研、标准、功效等内容另需核实来源，本轮只展示轻量结构与少量介绍。

### 6. 食材安全事件

保留农药残留、重金属与年份索引三个入口，以阅读列表方式呈现。没有核实的事件数据时展示资料待整理的空状态，不伪造事件标题、受害人数或官方处理信息。

页脚包含网站介绍、联系资料待补充说明和返回顶部入口，采用简洁排版。

## 动效

- 入场：侧栏淡入，标题和说明依次淡入并上移 16px；食材照片从比例 1.025 轻缓回到 1。整体 700–900ms，不设加载等待页。
- 滚动显现：内容进入视口后淡入并上移 20px，持续 500–650ms，每组项目错开 60–90ms；只播放一次。
- 摄影：悬停可微放大到 1.025，保持固定图像框，不能推挤文字。无需悬停即可访问按钮。
- 滚动使用浏览器原生机制，禁止强制整屏吸附与滚轮接管。首屏照片不使用无限动画。
- 用户设置减少动态效果时，取消位移、缩放、错峰和光滑滚动，所有内容立即可见。
- 不支持观察器或 JavaScript 加载失败时，正文仍能显示；动效不能成为内容的加载条件。

## 实现范围与页面状态

这是一个静态展示前端与本地交互演示，不包含购物车、支付、注册、后台或真实业务接口。适合采用可部署的静态 HTML/CSS/JavaScript 文件，模块区分导航、内容数据、页面渲染和动效，避免把所有代码堆在一个文件中。

首页是长页，六大栏目同时保留独立的列表和详情页面入口。详情支持返回列表，筛选支持重置，无结果时给出清楚提示。无报告时按钮显示资料状态而不下载虚构文件。

Sites 项目创建与发布在设计确认和实现验证完成后进行；新站默认私人访问。本轮没有创建外部 Site 或发布网站。

## 验收

1. 在 1440px 桌面、1024px 窄桌面和 390px 手机宽度检查，页面没有横向溢出、标题覆盖摄影或侧栏遮挡正文。
2. 六个栏目点击有效，手动上下滚动时高亮顺序正确，收起与展开不丢失当前位置。
3. 页面直接刷新及浏览器前进后退保持对应页面与锚点；详情保持所属栏目高亮。
4. 手机抽屉可通过菜单、栏目、遮罩和 Escape 操作，焦点不会丢失到页面外。
5. 减少动态效果模式下内容完整可见，所有流程仍可用。
6. 分类筛选、肥料饲料标签、返回列表、空结果和资料待补充状态均可检查。
7. 对照修订效果图核对米白背景、森林绿按钮、字体层级、侧栏比例、摄影裁切和各节留白；正文控件由代码实现，不能使用整张效果图替代 UI。
