## 选择的组织方式

采用企业展示网站常见的“顶部主导航 + 独立栏目页 + 页面内横向分栏”，比单一长页更便于进入具体内容。原站的长首页仍提供概要入口，新版点击主导航直接进入栏目页面。

不采用只把侧栏横过来、其余页面保持原样的方案，因为用户明确要求参考各页面格式；也不照搬参考企业的业务栏目，因为已有 Word 文档规定了网站范围。

## 全站外壳

左侧展示“菌养食材”品牌，六个顶部主栏目为：首页、菌养食材、肥料与饲料、基地溯源、科普知识、食材安全事件。搜索入口标为搜索食材，实际链接至食材列表筛选结果。

桌面可展开关联的二级入口；鼠标与键盘均可操作。主栏目本身可点击，不依赖悬停才能进入。手机改为顶部菜单按钮及展开菜单，支持关闭、Escape、焦点返回和点击链接后关闭。

所有页面共用深绿色页脚，提供六个栏目链接、网站介绍以及“界面示意 / 资料待补充”说明。无需虚构公司地址、电话、备案号或认证。

## 首页布局与允许文案

1. 横幅大图：基地或农业摄影；标题“从微生物，到日常食材”，副标题“连接食材、基地与生产记录”；按钮“浏览菌养食材”“查看基地溯源”。无额外宣传标签、虚构数据或奖项。
2. 网站介绍：左侧简短说明，右侧基地摄影，标题“了解菌养食材”，链接“了解更多”。保留微生物、种植与养殖、食材、检测与溯源四个关联入口。
3. 菌养食材：蔬菜类、瓜果类、家禽肉类、蛋奶类四个摄影入口及“查看全部食材”。
4. 肥料与饲料：微生物肥料与发酵饲料两个图文入口。
5. 基地溯源：横向图文区，入口进入种植/养殖基地及过程、管理、监测资料。
6. 科普知识与食材安全事件：图片与文章列表、风险索引、进入独立栏目页的按钮。
7. 全站页脚。

首页在单一白底系统内采用全宽摄影、图文双栏、开放产品列和资讯行来区分阅读节奏。

## 独立页面及分栏

独立的真实静态页面地址，支持刷新、收藏和浏览器前进后退。每类页面采用统一的顶栏、栏目横幅、当前位置、分栏、正文及页脚；详情页的关联入口继续可用。

| 栏目 | 分栏 / 列表 | 详情内容 |
| --- | --- | --- |
| 菌养食材 | 全部、蔬菜类、瓜果类、家禽肉类、蛋奶类；保留基地筛选、搜索与重置 | 产品信息、来源基地、批次资料、检测报告状态 |
| 肥料与饲料 | 肥料、饲料 | 分类成分、适用对象、使用与储存、质量资料、技术文章 |
| 基地溯源 | 种植基地、养殖基地 | 基地介绍、生产过程、日常管理、指标监测、关联食材 |
| 科普知识 | 全部、微生物分类与作用、菌养机理、技术方法、研究与应用、食品检测标准 | 标题、图片、正文与资料来源状态 |
| 食材安全事件 | 风险类型与年份筛选 | 时间、涉及食材、调查信息、风险类型与来源的版式示意 |
| 网站介绍 | 网站定位、栏目说明 | 图文说明与内容关系；不虚构企业历史 |

列表页保留筛选无结果和重置；详情资料不全时显示“待补充”。实际报告缺失时不提供假下载或合格结论。未找到的页面有清楚的返回入口。

肥料与饲料分别生成独立列表页面，与整合文档的两个产品页面对应；顶部栏目和页面内分栏均可进入。

## 实现边界

复用现有数据、摄影、图标与经验证的页面逻辑，在独立目录重新组织顶栏、首页与内页外壳。使用静态 HTML/CSS/JavaScript 与轻量生成脚本，生成独立路径的页面；页面内筛选和资料分栏使用真实查询参数或锚点。无需引入后台、登录、支付或新的业务服务。

本轮不改变原站，不重新解释“菌养”为蘑菇专卖，不补入未经提供的真实业务数据。新版源代码在完成后与现有 GitHub 项目一起保留，位于独立 `site-horizontal/` 目录。
