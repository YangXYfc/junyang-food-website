# 菌养食材网站

静态展示前端，依据三份 Word 文档与 A2 设计稿。源代码及可部署输出位于 `dist/`，无前端依赖安装步骤。

启动：`node server.mjs`，打开 `http://127.0.0.1:4173`。

测试：`node --test --test-isolation=none tests/logic.test.mjs`。

支持：长首页、左侧折叠导航、滚动高亮、手机抽屉、食材筛选与详情、肥料/饲料切换与详情、基地过程与监测资料、科普主题与文章、事件检索及详情版式。

图片和产品/基地条目用于界面示意；实际名称、价格、生产记录、检测报告、事件资料及联系方式待补充。没有填写检测合格结论、虚构认证或真实交易功能。

`dist/data.js` 维护演示内容，`logic.js` 是路由与筛选逻辑，`views.js` 是页面结构，`app.js` 负责交互，`styles.css` 是样式与动效。无需构建，可通过 Sites 静态部署。
